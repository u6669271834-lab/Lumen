# Lumen Game v0.1

Рабочий прототип игры, в которой репозиторий является канонической памятью мира.

## Принцип

- `world/` хранит утверждённые сведения о мире;
- игровой интерфейс читает мир из файлов репозитория;
- пользовательский прогресс сохраняется локально в браузере;
- браузер не изменяет GitHub и не переписывает канон;
- новые факты мира добавляются только отдельным подтверждённым изменением репозитория.

## Запуск

Из папки `projects/lumen-game` запустить локальный HTTP-сервер:

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Структура

- `index.html` — игровой экран;
- `styles.css` — визуальная система;
- `game.js` — загрузчик мира и игровой цикл;
- `world/manifest.json` — индекс сущностей;
- `world/canon.md` — правила канона;
- `world/schema.md` — формат данных;
- `world/state.initial.json` — стартовое состояние игрока;
- `world/locations/` — локации и переходы;
- `world/characters/` — персонажи;
- `world/events/event-log.json` — канонические события мира.

## Критерий v0.1

Игрок открывает игру, читает сцену, делает выбор, переходит между локациями, видит журнал пути и может продолжить с локального сохранения. Все сведения о мире загружаются из файлов `world/`.
