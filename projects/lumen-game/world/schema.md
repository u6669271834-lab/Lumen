# Схема данных мира v0.1

## Локация

```json
{
  "id": "location-id",
  "title": "Название",
  "eyebrow": "Короткий тип пространства",
  "description": ["Абзац 1", "Абзац 2"],
  "atmosphere": "Краткое описание состояния места",
  "characterIds": ["character-id"],
  "choices": [
    {
      "id": "choice-id",
      "label": "Текст выбора",
      "to": "target-location-id",
      "log": "Запись в личный журнал пути"
    }
  ]
}
```

## Персонаж

```json
{
  "id": "character-id",
  "name": "Имя",
  "role": "Роль",
  "description": "Каноническое описание",
  "speech": "Реплика для текущей версии"
}
```

## Каноническое событие

```json
{
  "id": "EVT-0001",
  "date": "2026-07-13",
  "title": "Событие",
  "cause": "Почему событие произошло",
  "consequences": ["Последствие"],
  "entityRefs": ["location-id"],
  "status": "canonical"
}
```

## Состояние игрока

Состояние игрока не является каноном мира. Оно содержит текущую локацию, посещённые места и личный журнал прохождения.
