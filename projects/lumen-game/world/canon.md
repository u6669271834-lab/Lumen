# Канон мира v0.1

## 1. Источник истины

Каноническим считается только содержимое ветки `main` после принятия изменений. Игровой интерфейс, чат, локальное сохранение и сгенерированный текст не создают канон автоматически.

## 2. Разделение слоёв

- **Канон мира** — подтверждённые локации, персонажи, законы и события в `world/`.
- **Состояние прохождения** — текущая позиция и история отдельного игрока в `localStorage`.
- **Предложение** — новый факт, который ещё не принят в репозиторий.

## 3. Неизменяемые основания v0.1

- Игрок носит роль Архитектора.
- Мир существует как сеть пространств, связанных Порогами.
- Архив хранит память о принятых решениях.
- Наблюдательная башня показывает возможные, но не утверждённые линии будущего.
- Хранитель Порога не управляет выбором игрока и не выдаёт предположение за истину.

## 4. Правило изменения мира

Новое каноническое событие должно иметь идентификатор, дату, причину, последствия и ссылку на изменённые сущности. Изменение принимается через отдельный commit или Pull Request после проверки.

## 5. Ограничение первой версии

Игра не записывает изменения в GitHub автоматически. Она только читает канон и сохраняет личный путь игрока локально.
