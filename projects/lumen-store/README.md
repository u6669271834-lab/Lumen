# Lumen Store

Lumen Store — витрина готовых промптов и системных пакетов Lumen.

Первая версия строится как проверяемая ручная клетка:

`продукт → карточка → выбор категории → запрос в Telegram → обратная связь`

## Что уже работает

- визуальная система «Световой архив»;
- каталог из шести стартовых продуктов;
- фильтрация по категориям;
- адаптивная вёрстка;
- заявки на конкретный продукт через `@lumen_designstudio`;
- production-сборка на Vinext/React.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm test
```
