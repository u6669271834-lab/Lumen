# Lumen Store — рабочее пространство v0.1

## Статус

Первая работающая витрина. Это не завершённая автоматизированная торговая
система: оплата, личный кабинет и автоматическая доставка цифрового товара пока
не подключены.

## Роли

- Архитектор — направление, вкус, человеческий смысл и окончательный выбор.
- ChatGPT — архитектура магазина, продуктовая структура, тексты, визуальная
  система, постановка и проверка производственных задач.
- Codex — реализация, тестирование и развитие программного контура.

## Текущий цикл

1. Посетитель открывает каталог.
2. Выбирает категорию и продукт.
3. Переходит в Telegram с готовым текстом запроса.
4. Lumen вручную подтверждает состав, цену и передачу продукта.
5. Результат и обратная связь используются для улучшения продукта.
