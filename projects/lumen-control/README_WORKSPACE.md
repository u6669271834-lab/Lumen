# Lumen Control — рабочее состояние v0.1

## Назначение

Единый визуальный вход в Lumen: диалог, решения, проекты, производство, Store и
архив. Панель не является текущим чатом ChatGPT и использует отдельный экземпляр
Lumen через OpenAI API.

## Что работает

- диалог с Lumen Core;
- защищённый серверный вызов Responses API;
- демо-режим без ключа или при отсутствии подключения;
- локальное сохранение сообщений, задач и журнала;
- навигация по проектам, производству, Store и архиву;
- ручное подтверждение важных действий.

## Что пока не работает

- автоматическая запись в GitHub из интерфейса;
- фактический запуск Codex;
- общая серверная память между устройствами;
- роли нескольких пользователей;
- автоматические платежи и выдача Store.

## Следующий этап

Подключить безопасный серверный Action Gateway: разрешённые действия,
подтверждение Архитектора, исполнение, проверка результата и запись события.
