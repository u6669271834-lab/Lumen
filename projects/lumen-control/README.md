# Lumen Control

Центральный кабинет Архитектора для диалога с Lumen, управления проектами,
производственной очередью, Lumen Store и архитектурной памятью.

## Режимы

- `real` — серверный вызов OpenAI Responses API;
- `demo` — честный локальный ответ без имитации настоящего вызова;
- `error` — команда сохраняется локально, интерфейс сообщает о разрыве связи.

## Безопасность

- `OPENAI_API_KEY` используется только серверным маршрутом;
- `.env.local` исключён из Git;
- внешние действия пока не исполняются автоматически;
- действия с последствиями проходят через подтверждение Архитектора.

## Запуск

```bash
npm ci
npm run dev
```
