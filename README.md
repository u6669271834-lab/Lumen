# Lumen

**Lumen — цифровая студия дизайна и AI-система совместной работы Михаила и центрального ChatGPT.**

Этот репозиторий является новым каноническим источником истины проекта с 12 июля 2026 года.

## Роли

* Михаил задаёт смысл, направление, ограничения и принимает ключевые решения.
* Центральный ChatGPT проектирует систему, формулирует решения и координирует работу.
* Codex исполняет утверждённые технические задания в репозитории.
* Технические инструменты подключаются после ручной проверки.

## Правило источника истины

Актуальное состояние определяется содержимым ветки `main`. Старые репозитории, чаты, память и локальные файлы используются только как материал для восстановления и уступают последнему принятому решению в этом репозитории.

## Текущий этап

Контролируемое восстановление структуры, канона, реестра проектов и Lumen Workspace.
